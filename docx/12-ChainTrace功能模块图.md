2. 用户端 (C 端) 功能模块
2.1 地址查询模块
┌─────────────────────────────────────────┐
│          地址查询模块                    │
├─────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐   │
│  │  地址搜索    │  │  地址详情    │   │
│  └──────────────┘  └──────────────┘   │
│  ┌──────────────┐  ┌──────────────┐   │
│  │  标签管理    │  │  收藏地址    │   │
│  └──────────────┘  └──────────────┘   │
│  ┌──────────────┐  ┌──────────────┐   │
│  │  地址对比    │  │  导出报告    │   │
│  └──────────────┘  └──────────────┘   │
└─────────────────────────────────────────┘

功能说明:
- 地址搜索: 支持输入区块链地址、域名、标签进行搜索
- 地址详情: 显示地址基本信息、余额、交易历史、风险评级
- 标签管理: 为用户自定义地址标签，支持分类管理
- 收藏地址: 收藏常用地址，快速访问
- 地址对比: 对比多个地址的风险特征和交易模式
- 导出报告: 生成地址分析报告，支持 PDF/Excel 导出

- 路径追踪: 追踪资金从源头到终点的路径
- 时间线视图: 按时间轴展示交易历史
- 关联分析: 分析交易之间的关联关系

┌─────────────────────────────────────────┐
│          风险评估模块                    │
├─────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐   │
│  │  风险评分    │  │  风险等级    │   │

功能说明:

- 风险等级: 低/中/高/极高四个等级
- 风险因素: 展示影响风险评分的具体因素
- 风险报告: 生成详细的风险评估报告
- 风险预警: 对高风险地址/交易进行预警
- 风险评估: 批量评估多个地址的风险

5. 核心服务功能
5.1 区块链数据服务
- 地址解析: 解析区块链地址，获取地址信息
- 交易查询: 查询交易详情，包括输入输出、手续费等
- 区块查询: 查询区块信息，包括交易列表、时间戳等
- 数据同步: 同步区块链数据，保持数据最新
- 数据缓存: 缓存热点数据，提高查询性能
5.2 风险分析服务
- 混币检测: 检测地址是否使用混币服务
- 风险评分: 计算地址/交易的风险分数
- 欺诈识别: 识别欺诈行为和模式
- 威胁情报: 整合多方威胁情报数据
- 实时预警: 对高风险行为进行实时预警
5.3 用户服务
- 认证鉴权: 用户登录、注册、权限验证
- 用户管理: 用户信息 CRUD、状态管理
- 权限控制: 基于角色的权限控制 (RBAC)
- 会话管理: 用户会话创建、刷新、失效
- 个人中心: 用户资料、设置、偏好
5.4 内容服务
- 内容管理: 内容发布、编辑、删除
- 内容审核: 自动审核 + 人工审核
- 消息通知: 站内信、邮件、短信通知
- 搜索索引: 内容索引、全文搜索
- 内容推荐: 基于用户行为的推荐
5.5 支付服务
- 支付处理: 处理支付请求，调用支付网关
- 订单管理: 订单创建、查询、状态更新
- 结算管理: 结算周期、分成计算、打款
- 发票管理: 发票生成、下载、邮寄
- 退款处理: 退款申请、审核、执行
