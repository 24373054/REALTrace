ChainTrace 用户端（C 端）功能手册（网页端）
文档信息
- 版本: v1.0
- 创建时间: 2026-03-12
- 适用平台: 网页端 (Web)
- 维护团队: ChainTrace 产品团队

---
1. 快速开始
1.1 访问平台
- 官方网站: https://chaintrace.io
- 支持浏览器: Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- 推荐分辨率: 1920x1080 及以上
1.2 注册账号
1. 点击首页右上角"注册"按钮
2. 输入邮箱地址，设置密码
3. 查收验证邮件，点击验证链接
4. 完成注册，登录系统
1.3 登录系统
1. 点击首页右上角"登录"按钮
2. 输入邮箱和密码
3. 勾选"记住我"可保持登录状态 7 天
4. 点击"登录"进入系统

2. 首页功能
2.1 搜索框
- 地址搜索: 输入区块链地址 (如 0x...)
- 交易搜索: 输入交易哈希 (如 0x...)
- 域名搜索: 输入 ENS 域名 (如 example.eth)
- 标签搜索: 输入已保存的标签名称
2.2 快捷入口
- 地址查询: 快速查询地址信息
- 交易追踪: 追踪交易流向
- 风险评估: 评估地址风险
- 可视化分析: 查看交易图谱
2.3 数据概览
- 总查询次数: 平台累计查询次数
- 已分析地址: 已分析的独特地址数
- 监控中地址: 用户正在监控的地址数
- 风险预警数: 今日发出的风险预警数

3. 地址查询功能
3.1 基本查询
操作路径: 首页搜索框 → 输入地址 → 回车
显示内容:
- 地址信息: 地址、类型、网络
- 余额信息: 当前余额、USD 估值
- 风险评级: 风险分数、风险等级
- 交易统计: 总交易数、首次/末次交易时间
- 标签信息: 系统标签、用户标签
3.2 详细信息
操作路径: 地址详情页 → 切换标签页
基本信息页
- 地址详情
- 余额历史
- 风险评分趋势
- 关联地址数
交易记录页
- 交易列表 (支持分页)
- 按时间排序
- 按金额筛选
- 导出交易记录
资金流向页
- 流入交易
- 流出交易
- 资金流向图
- 主要交易对手
风险报告页
- 风险评分详情
- 风险因素分析
- 关联风险地址
- 完整风险报告
3.3 高级功能
收藏地址
操作步骤:
1. 进入地址详情页
2. 点击右上角"⭐ 收藏"按钮
3. 选择或输入标签名称
4. 点击"确定"保存

添加标签
操作步骤:
1. 进入地址详情页
2. 点击"标签管理"按钮
3. 输入标签名称和描述
4. 选择标签分类
5. 点击"保存"

导出报告
操作步骤:
1. 进入地址详情页
2. 点击右上角"导出报告"按钮
3. 选择报告类型 (简要/详细)
4. 选择导出格式 (PDF/Excel)
5. 点击"下载"

4. 交易追踪功能
4.1 交易查询
操作路径: 导航栏 → 交易追踪 → 输入交易哈希
显示内容:
- 交易基本信息: 哈希、区块号、时间戳
- 交易详情: 发送者、接收者、金额、手续费
- 输入输出: 所有输入输出地址
- 确认状态: 确认数、是否已确认
4.2 资金流向追踪
操作路径: 交易详情页 → 资金流向标签页
功能说明:
- 可视化路径: 图形化展示资金流动路径
- 路径深度: 支持追踪 1-10 层路径
- 节点信息: 点击节点查看详情
- 路径导出: 导出路径图为图片
4.3 时间线视图
操作路径: 交易详情页 → 时间线标签页
功能说明:
- 时间轴展示: 按时间顺序展示所有相关交易
- 交易详情: 点击交易查看详情
- 筛选条件: 按时间范围、金额筛选
- 导出时间线: 导出为 PDF 报告

5. 风险评估功能
5.1 风险评分
评分标准:
- 0-20 分: 低风险 (绿色)
- 21-50 分: 中低风险 (蓝色)
- 51-80 分: 中高风险 (橙色)
- 81-100 分: 高风险 (红色)
评分维度:
- 混币服务使用 (20%)
- 高风险地址关联 (25%)
- 交易模式异常 (20%)
- 黑名单匹配 (20%)
- 其他风险因素 (15%)
5.2 风险因素分析
操作路径: 地址详情页 → 风险报告标签页 → 风险因素
显示内容:
- 风险因素列表: 所有影响评分的因素
- 影响程度: 每个因素的影响分值
- 详细说明: 每个因素的具体说明
- 证据展示: 支持证据的交易/地址链接
5.3 风险预警
操作路径: 用户中心 → 消息通知 → 风险预警
功能说明:
- 实时监控: 对收藏地址进行实时监控
- 预警条件: 可配置预警触发条件
- 通知方式: 站内信、邮件、短信
- 预警历史: 查看所有预警记录

6. 可视化分析功能
6.1 交易图谱
操作路径: 导航栏 → 可视化分析 → 交易图谱
功能说明:
- 力导向图: 展示地址间的交易关系
- 节点大小: 按交易金额/次数缩放
- 节点颜色: 按风险等级着色
- 边粗细: 按交易金额缩放
- 交互操作: 拖拽、缩放、点击查看详情
操作技巧:
- 鼠标滚轮：缩放图谱
- 鼠标拖拽：移动视图
- 双击节点：聚焦该节点
- 右键菜单：更多操作选项
6.2 资金流向图
操作路径: 导航栏 → 可视化分析 → 资金流向
功能说明:
- 桑基图: 展示资金从源头到终点的流动
- 流量宽度: 按金额比例显示
- 颜色编码: 不同来源/目的地不同颜色
- 交互查询: 点击流查看详情
6.3 热力图
操作路径: 导航栏 → 可视化分析 → 热力图
功能说明:
- 地理分布: 展示交易活动的地理分布
- 时间维度: 支持按小时/天/月查看
- 强度显示: 颜色深浅表示活跃度
- 数据下钻: 点击区域查看详情
6.4 趋势图
操作路径: 导航栏 → 可视化分析 → 趋势图
功能说明:
- 折线图: 展示数据随时间变化
- 柱状图: 对比不同类别数据
- 面积图: 展示累积趋势
- 多图对比: 支持多个指标对比

7.1 个人信息
操作路径: 右上角头像 → 用户中心 → 个人信息
可编辑内容:
- 用户名
- 头像
- 个人简介
- 联系方式
7.2 账户设置
操作路径: 用户中心 → 账户设置
功能说明:
- 修改密码: 设置新密码
- 绑定邮箱: 修改绑定邮箱
- 绑定手机: 绑定/解绑手机号
- 双重验证: 开启/关闭 2FA
7.3 我的收藏
操作路径: 用户中心 → 我的收藏
功能说明:
- 收藏列表: 查看所有收藏的地址
- 标签管理: 管理收藏标签
- 批量操作: 批量删除/导出
- 搜索筛选: 按标签/名称搜索
7.4 搜索历史
操作路径: 用户中心 → 搜索历史
功能说明:
- 历史记录: 查看所有搜索记录
- 快速访问: 点击记录快速访问
- 删除记录: 删除单个或全部记录
- 导出历史: 导出搜索历史为 CSV
7.5 消息通知
操作路径: 用户中心 → 消息通知
通知类型:
- 系统通知: 平台公告、维护通知
- 风险预警: 收藏地址的风险预警
- 审核通知: 内容审核结果通知
- 活动通知: 平台活动、优惠信息

10. 常见问题
10.1 查询相关问题
Q: 为什么有些地址查不到信息？A: 可能是因为该地址还没有任何交易记录，或者我们的数据源尚未同步到该地址。
Q: 风险评分多久更新一次？A: 风险评分会在每次有新交易时重新计算，同时系统会每天凌晨进行一次全量更新。
10.2 会员相关问题
Q: 会员过期后数据会删除吗？A: 不会。您的收藏、标签、搜索历史等数据会永久保存。会员过期后只是无法继续使用付费功能。
Q: 可以退款吗？A: 电子虚拟产品一经购买不支持退款，除非有技术故障导致无法使用。
10.3 技术相关问题
Q: 支持哪些区块链？A: 目前支持 Ethereum、Bitcoin、BSC、Polygon 等主流公链，更多链正在陆续上线。
Q: 数据延迟多久？A: 一般交易确认后 1-2 分钟内可查询到，高峰期可能延迟到 5 分钟。
