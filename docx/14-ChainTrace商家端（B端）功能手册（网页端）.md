1. 快速开始
1.1 企业注册
1. 访问 https://business.chaintrace.io
2. 点击"企业注册"
3. 填写企业信息（公司名称、统一社会信用代码、联系人等）
4. 上传企业资质证明（营业执照、法人身份证等）
5. 等待审核（1-2 个工作日）
6. 审核通过后使用注册邮箱登录
1.2 登录系统
1. 输入企业注册邮箱
2. 输入密码
3. 如开启 2FA，输入验证码
4. 点击"登录"
1.3 控制台概览
登录后进入企业控制台，显示：
- 今日概览: 查询次数、拦截次数、预警数量
- API 使用: 今日调用量、配额使用情况
- 待处理: 待审核订单、待处理预警
- 快速入口: 常用功能快捷入口

2. 企业风控模块
2.1 风控策略配置
操作路径: 风控管理 → 策略配置
策略类型
- 地址风控: 对特定地址进行风控
- 交易风控: 对交易行为进行风控
- 用户风控: 对用户账户进行风控
- 自定义风控: 自定义风控规则
配置步骤
1. 点击"新建策略"
2. 选择策略类型
3. 设置触发条件
4. 设置处置动作
5. 设置策略优先级
6. 保存并启用

触发条件
- 风险评分 > 阈值
- 交易金额 > 阈值
- 关联黑名单地址
- 使用混币服务
- 异常交易模式
- 自定义规则 (支持表达式)
处置动作
- 警告: 发送预警通知
- 限制: 限制部分功能
- 拦截: 直接拦截交易
- 审核: 转人工审核
- 自定义: 调用 Webhook
2.2 实时监控
操作路径: 风控管理 → 实时监控
监控面板
- 实时交易监控: 显示正在进行的交易
- 风险预警实时流: 实时滚动的预警信息
- 拦截记录: 被拦截的交易记录
- 系统状态: API 可用性、响应时间
预警设置
1. 进入"预警配置"
2. 选择预警类型
3. 设置触发条件
4. 选择通知方式 (邮件/短信/Webhook)
5. 设置接收人
6. 保存配置

2.3 黑名单管理
操作路径: 风控管理 → 黑名单管理
功能说明
- 黑名单列表: 查看所有黑名单地址
- 添加黑名单: 手动添加地址到黑名单
- 批量导入: 批量导入黑名单 (CSV/Excel)
- 黑名单来源: 系统自动/手动添加/第三方同步
- 标签管理: 为黑名单地址添加标签
- 导出黑名单: 导出完整黑名单列表
添加黑名单
操作步骤:
1. 点击"添加黑名单"
2. 输入地址 (支持批量，每行一个)
3. 选择风险类型
4. 填写备注说明
5. 选择是否同步到所有业务线
6. 点击"确认添加"

2.4 白名单管理
操作路径: 风控管理 → 白名单管理
功能说明
- 白名单列表: 查看所有白名单地址
- 添加白名单: 手动添加可信地址
- 有效期设置: 设置白名单有效期
- 优先级: 白名单优先于黑名单
- 自动过期: 支持设置自动过期
2.5 风控报表
操作路径: 风控管理 → 风控报表
报表类型
- 拦截报表: 统计拦截交易数量、金额
- 预警报表: 统计预警数量、类型分布
- 风险趋势: 风险评分变化趋势
- 策略效果: 各策略的拦截效果分析
报表导出
- 支持时间范围选择
- 支持多维度筛选
- 支持 PDF/Excel/CSV 导出
- 支持定时自动生成

3. 合规审查模块
3.1 KYC 审查
操作路径: 合规管理 → KYC 审查
审查流程
1. 用户上传身份信息
2. 系统自动初审 (OCR 识别、人脸比对)
3. 人工复审 (如需)
4. 审查结果通知用户
5. 审查记录存档

审查内容
- 身份验证: 姓名、身份证号、人脸照片
- 地址验证: 居住证明、账单
- 职业验证: 工作证明、收入证明
- 资金来源: 资金来源说明、银行流水
审查标准
- 自动通过: 信息完整、验证通过
- 人工审核: 信息存疑、需要补充
- 拒绝: 信息造假、验证失败
3.2 AML 审查
操作路径: 合规管理 → AML 审查
审查功能
- 交易监控: 监控可疑交易模式
- 大额交易报告: 自动识别大额交易
- 可疑交易报告: 识别可疑交易行为
- 名单筛查: 对照制裁名单、PEP 名单
可疑交易特征
- 短时间内频繁交易
- 交易金额接近报告阈值
- 与高风险地址交易
- 异常交易时间
- 拆分交易规避监控
3.3 合规报告
操作路径: 合规管理 → 合规报告
报告类型
- 月度合规报告: 每月自动生成
- 季度合规报告: 每季度自动生成
- 年度合规报告: 每年自动生成
- 定制报告: 按需生成定制报告
报告内容
- 合规审查统计
- 可疑交易报告
- 大额交易报告
- 风险事件汇总
- 合规建议
3.4 监管对接
操作路径: 合规管理 → 监管对接
对接功能
- 监管接口: 对接监管机构系统
- 数据上报: 自动上报合规数据
- 监管查询: 接收监管查询请求
- 监管通知: 接收监管通知文件

10. 常见问题
10.1 企业注册问题
Q: 企业注册需要哪些材料？A: 需要营业执照扫描件、法人身份证正反面、企业授权书 (如非法人操作)。
Q: 审核需要多久？A: 一般 1-2 个工作日，工作日 9:00-18:00 提交的当天可审核。
10.2 API 使用问题
Q: API 调用失败怎么办？A: 检查错误码，常见原因包括：密钥无效、配额用完、参数错误、网络问题。
Q: 如何增加 API 配额？A: 在"API 服务 → 配额管理"中购买更多配额，或联系销售定制企业方案。
10.3 账单发票问题
Q: 如何申请发票？A: 在"订单管理 → 发票管理"中为已支付订单申请发票，支持电子发票和纸质发票。
Q: 支持专票吗？A: 支持。申请时选择"专用发票"，需要填写完整的税务信息。
