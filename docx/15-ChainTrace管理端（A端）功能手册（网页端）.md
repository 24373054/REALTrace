文档信息
- 版本: v1.0
- 创建时间: 2026-03-12
- 适用平台: 网页端 (Web)
- 维护团队: ChainTrace 产品团队

---
1. 快速开始
1.1 访问地址
- 管理端网址: https://admin.chaintrace.io
- 访问权限: 仅限授权管理员访问
- IP 限制: 可配置 IP 白名单
1.2 登录系统
1. 输入管理员账号 (邮箱)
2. 输入密码
3. 输入 2FA 验证码 (如已开启)
4. 点击"登录"
1.3 控制台首页
登录后显示：
- 核心指标卡片: 用户数、订单数、收入、活跃度
- 实时数据: 在线用户、请求量、错误率
- 待处理事项: 待审核内容、待处理工单
- 快捷入口: 常用功能快速入口
- 系统状态: 服务健康度、资源使用情况

2. 用户管理模块
2.1 用户列表
操作路径: 用户管理 → 用户列表
列表内容
- 用户 ID
- 用户名/邮箱
- 用户类型 (C 端/B 端/内部)
- 会员等级
- 注册时间
- 最后登录时间
- 用户状态 (正常/封禁/待审核)
- 操作列 (查看详情/编辑/封禁/删除)
筛选条件
- 关键词搜索: 用户名、邮箱、手机号
- 用户类型: C 端用户/B 端企业/内部账号
- 用户状态: 正常/封禁/待审核/已注销
- 注册时间: 选择时间范围
- 会员等级: 免费/基础/专业/企业
批量操作
- 批量封禁用户
- 批量解封用户
- 批量删除用户
- 批量导出用户信息
- 批量发送邮件
2.2 用户详情
操作路径: 用户列表 → 点击用户 → 用户详情
基本信息标签页
- 用户 ID、用户名、头像
- 邮箱、手机号
- 注册时间、最后登录时间
- 用户状态、封禁原因
- 实名认证信息 (如已认证)
账户信息标签页
- 会员等级、会员到期时间
- 账户余额、积分
- API 配额使用情况
- 绑定设备列表
行为记录标签页
- 登录日志 (时间、IP、设备)
- 操作日志 (关键操作记录)
- 搜索历史 (最近搜索记录)
- 交易记录 (如适用)
关联数据标签页
- 收藏的地址列表
- 创建的报告列表
- 提交的工单列表
- 收到的消息列表
2.3 用户审核
操作路径: 用户管理 → 用户审核
待审核列表
- 企业注册审核: 新注册的企业用户
- 实名认证审核: 用户提交的实名信息
- 资料修改审核: 用户修改关键资料
- 解封申请审核: 被封用户的解封申请
审核操作
1. 查看待审核用户信息
2. 核实提交的材料/信息
3. 点击"通过"或"拒绝"
4. 如拒绝，填写拒绝原因
5. 系统自动通知用户审核结果

审核标准
- 企业审核: 营业执照真实性、法人身份验证
- 实名审核: 身份证真实性、人脸比对结果
- 资料审核: 信息完整性、真实性
- 解封审核: 违规情况说明、整改证明
2.4 用户权限
操作路径: 用户管理 → 权限管理
角色管理
- 角色列表: 查看所有预定义角色
- 创建角色: 自定义新角色
- 编辑角色: 修改角色权限
- 删除角色: 删除不再使用的角色
预定义角色
- 超级管理员: 所有权限
- 运营管理员: 用户管理、内容审核
- 技术管理员: 系统配置、日志查看
- 财务管理员: 订单管理、发票管理
- 客服管理员: 工单处理、消息发送
- 普通管理员: 只读权限 + 部分操作
权限配置
- 功能权限: 菜单访问权限、按钮操作权限
- 数据权限: 数据查看范围、数据操作范围
- API 权限: API 调用权限、配额管理权限
权限分配
- 为用户分配角色
- 查看用户拥有的所有权限
- 批量分配角色
- 权限变更审计日志

3. 内容审核模块
3.1 待审核列表
操作路径: 内容审核 → 待审核列表
审核类型
- 用户发布内容: 文章、评论、动态
- 用户上传文件: 图片、视频、文档
- 用户私信: 举报的私信内容
- 企业提交资料: 企业认证材料
列表信息
- 内容 ID、内容类型
- 提交用户、提交时间
- 审核状态 (待审核/自动审核/人工审核)
- 风险评分 (AI 预审结果)
- 操作列 (通过/拒绝/转人工)
筛选条件
- 内容类型
- 提交时间范围
- 审核状态
- 风险等级
- 关键词搜索
3.2 审核操作
操作路径: 待审核列表 → 点击内容 → 审核详情
审核界面
- 内容预览: 查看待审核的完整内容
- AI 预审结果: 显示 AI 识别的风险点
- 用户信息: 内容提交者的信息
- 历史记录: 该用户的历史审核记录
审核决策
通过:
- 内容符合规范
- 点击"通过"按钮
- 可选填写备注
- 内容立即发布

拒绝:
- 内容违反规范
- 点击"拒绝"按钮
- 必须选择拒绝原因
- 可选填写详细说明
- 用户收到拒绝通知

转人工:
- AI 无法判断
- 需要专业审核
- 点击"转人工审核"
- 分配给高级审核员

批量审核
- 选择多条待审核内容
- 批量通过/拒绝
- 适用于明显合规/违规的内容
3.3 审核规则
操作路径: 内容审核 → 规则配置
关键词过滤
- 敏感词库: 管理敏感词列表
- 词库分类: 政治、色情、暴力、广告等
- 添加关键词: 手动添加敏感词
- 批量导入: 批量导入词库
- 匹配模式: 精确匹配/模糊匹配/正则表达式
图片识别
- AI 识别服务: 配置 AI 图片识别服务
- 识别类型: 色情、暴力、政治、广告
- 识别阈值: 设置判定阈值
- 人工复核: 设置需要人工复核的阈值
行为规则
- 频率限制: 限制用户发布频率
- 内容长度: 限制内容最小/最大长度
- 禁止内容: 禁止特定类型内容
- 自动审核: 配置自动审核规则
规则优先级
- 高优先级规则先执行
- 可设置规则执行顺序
- 支持规则组合 (AND/OR)
3.4 审核统计
操作路径: 内容审核 → 审核统计
统计维度
- 审核量统计: 按日/周/月统计审核量
- 通过率统计: 各类内容的通过率
- 审核员绩效: 各审核员的工作量、质量
- 违规类型分布: 各类违规内容的占比
可视化图表
- 审核量趋势图 (折线图)
- 通过率对比图 (柱状图)
- 违规类型分布 (饼图)
- 审核员绩效排名 (排行榜)
导出报表
- 导出审核统计报表
- 导出审核员绩效报表
- 导出违规内容分析报告

4. 数据统计模块
4.1 数据概览
操作路径: 数据统计 → 数据概览
核心指标卡片
- 用户指标: 总用户数、新增用户、活跃用户
- 内容指标: 总内容数、新增内容、审核通过数
- 订单指标: 总订单数、订单金额、退款率
- 收入指标: 总收入、会员收入、API 收入
实时数据
- 实时在线用户数
- 实时 API 请求量
- 实时订单量
- 系统负载 (CPU/内存)
趋势图表
- 用户增长趋势 (7 日/30 日/90 日)
- 订单金额趋势
- 收入趋势
- 活跃度趋势
数据对比
- 同比 (与去年同期对比)
- 环比 (与上一周期对比)
- 目标完成率
4.2 用户统计
操作路径: 数据统计 → 用户统计
用户增长
- 新增用户: 按日/周/月统计
- 流失用户: 按日/周/月统计
- 净增用户: 新增 - 流失
- 用户增长率: 环比增长率
用户活跃
- DAU: 日活跃用户数
- MAU: 月活跃用户数
- 活跃率: DAU/总用户数
- 留存率: 次日/7 日/30 日留存
用户分布
- 地域分布: 用户按国家/省份分布
- 年龄分布: 用户年龄结构
- 设备分布: iOS/Android/Web
- 来源分布: 自然搜索/社交媒体/直接访问
用户行为
- 页面访问: 各页面 PV/UV
- 功能使用: 各功能使用频率
- 停留时长: 平均停留时长
- 转化漏斗: 关键流程转化率
4.3 内容统计
操作路径: 数据统计 → 内容统计
内容发布
- 发布量: 按类型统计发布量
- 类型分布: 各类型内容占比
- 热度排名: 最热门内容 TOP10
- 创作者排名: 最活跃创作者 TOP10
内容互动
- 阅读量: 总阅读量、平均阅读量
- 点赞数: 总点赞数、点赞率
- 评论数: 总评论数、评论率
- 分享数: 总分享数、分享率
内容质量
- 优质内容: 优质内容占比
- 违规内容: 违规内容占比
- 审核通过率: 审核通过率趋势
- 平均审核时长: 审核效率指标
4.4 业务统计
操作路径: 数据统计 → 业务统计
订单统计
- 订单量: 按日/周/月统计
- 订单金额: GMV 统计
- 退款率: 退款订单占比
- 平均客单价: 订单平均金额
支付统计
- 支付方式: 各支付方式占比
- 支付成功率: 支付成功/失败统计
- 支付金额: 各支付方式金额
- 支付时长: 平均支付时长
收入统计
- 总收入: 按日/周/月统计
- 会员收入: 会员订阅收入
- API 收入: API 调用收入
- 分成收入: 创作者分成支出
成本统计
- 服务器成本: 云资源费用
- 带宽成本: 流量费用
- 人力成本: 运营/技术成本
- 其他成本: 第三方服务费用
4.5 报表生成
操作路径: 数据统计 → 报表生成
内置报表模板
- 日报: 每日运营数据汇总
- 周报: 每周运营数据汇总
- 月报: 每月运营数据汇总
- 年报: 每年运营数据汇总
- 定制报表: 自定义报表模板
自定义报表
1. 点击"新建报表"
2. 选择报表类型 (日/周/月/自定义)
3. 选择数据指标
4. 选择数据维度
5. 设置筛选条件
6. 设置报表样式
7. 保存报表模板

定时报表
- 设置报表生成周期
- 设置生成时间
- 设置接收人 (邮件)
- 设置报表格式 (PDF/Excel)
报表导出
- 单份报表导出
- 批量导出历史报表
- 导出格式选择
- 导出范围选择

操作路径: 日志监控 → 监控告警
系统监控
- CPU 使用率: 实时/历史
- 内存使用率: 实时/历史
- 磁盘使用率: 实时/历史
- 网络流量: 入站/出站流量
应用监控
- 请求量: QPS/TPS
- 响应时间: P50/P90/P99
- 错误率: 错误请求占比
- 可用性: 服务可用性
业务监控
- 用户数: 在线用户/新增用户
- 订单量: 订单量/订单金额
- 收入: 实时收入/累计收入
- API 调用: API 调用量/成功率
告警配置
1. 点击"新建告警"
2. 选择监控指标
3. 设置告警条件 (如 CPU>80%)
4. 设置告警级别 (警告/严重/紧急)
5. 设置通知方式 (邮件/短信/Webhook)
6. 设置接收人
7. 设置告警频率 (立即/聚合)
8. 保存并启用

告警历史
- 查看所有历史告警
- 告警时间线
- 告警处理记录
- 告警统计报表

8. 常见问题
8.1 权限问题
Q: 如何添加新管理员？A: 超级管理员可以在"用户管理 → 权限管理"中为用户分配管理员角色。
Q: 忘记了管理员密码怎么办？A: 联系系统所有者进行密码重置，或通过数据库重置 (需要数据库权限)。
8.2 性能问题
Q: 管理端响应慢怎么办？A: 检查"日志监控 → 访问日志"中的慢请求，优化数据库索引，增加缓存。
Q: 如何优化大数据量查询？A: 使用分页查询，添加合适的索引，考虑使用 Elasticsearch 进行全文搜索。
8.3 安全问题
Q: 如何限制管理端访问 IP？A: 在"系统配置 → 安全配置 → 访问控制"中配置 IP 白名单。
Q: 如何查看谁修改了配置？A: 在"日志监控 → 操作日志"中筛选"配置变更"类型的日志。
