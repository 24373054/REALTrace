1. 会员体系概述
1.1 设计理念
ChainTrace 会员体系旨在为不同需求的用户提供分层服务，通过差异化的权益设计，让用户根据使用频率和功能需求选择合适的会员等级，同时为平台创造可持续的营收模式。
1.2 设计原则
- 价值导向: 每个等级的权益都有明确的使用价值
- 阶梯设计: 等级之间有明显的功能/数量差异
- 灵活选择: 支持多种购买时长和支付方式
- 透明定价: 价格清晰，无隐藏费用
- 易于理解: 权益描述简单明了

2. 免费版会员 (Free)
2.1 基本信息
- 价格: ¥0/月 (永久免费)
- 购买方式: 注册即享
- 适用人群: 偶尔使用、体验功能
2.2 核心权益
查询权益
- 每日查询次数: 10 次/天
- 查询类型: 地址查询、交易查询
- 查询深度: 基础信息 (不包含深度分析)
- 查询速度: 标准速度 (无优先队列)
数据权益
- 查看地址详情: ✅ 可查看
- 查看交易详情: ✅ 可查看
- 资金流向图: ❌ 不可用
- 交易图谱: ❌ 不可用
- 历史数据: 最近 30 天数据
分析权益
- 风险评分: ✅ 基础评分 (0-100)
- 风险因素: ❌ 不可查看
- 关联分析: ❌ 不可用
- 深度报告: ❌ 不可用
导出权益
- 导出报告: 1 次/天 (仅 PDF 格式)
- 导出格式: PDF (基础版)
- 导出内容: 基础信息报告
- 批量导出: ❌ 不可用
监控权益
- 监控地址数: 1 个
- 风险预警: ❌ 不可用
- 实时监控: ❌ 不可用
- 预警通知: ❌ 不可用
其他权益
- 客服支持: 社区支持 (无专人客服)
- API 访问: ❌ 不可用
- 优先体验: ❌ 不可用
- 专属标识: ❌ 无标识
2.3 使用限制
- 每日查询次数用完需等待次日刷新
- 无法查看深度分析报告
- 无法使用可视化高级功能
- 无法设置风险预警
- 无法访问 API 接口
2.4 升级引导
- 查询次数用完时提示升级
- 查看高级功能时提示升级
- 导出报告时提示升级
- 设置预警时提示升级

7. 会员购买流程
7.1 购买步骤
```Plain Text
1. 进入会员中心
2. 选择会员等级
3. 选择购买时长 (月/季/半年/年)
4. 确认订单信息
5. 选择支付方式
6. 完成支付
7. 会员立即生效
```
7.2 支付方式
- 支付宝: 支持支付宝扫码支付
- 微信支付: 支持微信扫码支付
- 银联卡: 支持各大银行信用卡/借记卡
- 加密货币: 支持 USDT (TRC20/ERC20)、BTC
7.3 支付安全
- HTTPS 加密传输
- 支付接口对接官方支付网关
- 不存储用户支付信息
- 支付完成后立即激活会员

8. 会员续费管理
8.1 自动续费
- 开启方式: 会员中心 → 续费管理 → 开启自动续费
- 扣费时间: 到期前 3 天自动扣费
- 扣费失败: 连续 3 次扣费失败后关闭自动续费
- 关闭方式: 随时可在会员中心关闭自动续费
8.2 手动续费
- 续费入口: 会员中心 → 续费
- 续费优惠: 提前 7 天续费享 9 折
- 续费保期: 续费后有效期顺延
8.3 会员降级
- 自动降级: 会员过期后自动降为免费版
- 数据保留: 所有历史数据永久保留
- 权益失效: 付费权益立即失效
8.4 会员升级
- 随时升级: 可在会员中心随时升级
- 费用补差: 只需补交差价
- 有效期: 新会员有效期从升级日起算

9. 退款政策
9.1 退款条件
- 7 天无理由: 购买 7 天内可申请退款
- 未使用服务: 未使用的服务可全额退款
- 已使用服务: 已使用的服务按比例退款
- 特殊商品: 促销商品不支持退款
9.2 退款流程
```Plain Text
1. 提交退款申请 (填写退款原因)
2. 客服审核 (1-3 个工作日)
3. 审核通过 (原路退回)
4. 审核拒绝 (说明拒绝原因)
```
9.3 退款说明
- 退款原路返回，3-7 个工作日到账
- 退款后会员立即失效
- 已导出的报告可继续查看
- 已使用的查询次数不退费

10. 常见问题
10.1 会员权益问题
Q: 会员过期后数据会删除吗？A: 不会。您的所有数据 (收藏、标签、搜索历史、报告) 都会永久保存。会员过期后只是无法继续使用付费功能。
Q: 可以多人共用一个会员账号吗？A: 不建议。会员账号仅限个人使用，发现异常使用可能会被封禁。团队使用建议购买企业版。
Q: 会员可以转让吗？A: 不支持转让。会员账号与注册邮箱绑定，不可转让。
10.2 支付相关问题
Q: 支付失败怎么办？A: 检查网络连接，确认支付余额充足，或更换支付方式重试。如仍失败，联系技术支持。
Q: 支持开发票吗？A: 支持。支付完成后可在"订单管理"中申请电子发票。
Q: 加密货币支付有手续费吗？A: 区块链网络手续费由用户承担，ChainTrace 不收取额外手续费。
10.3 使用相关问题
Q: API 调用次数怎么计算？A: 每次 API 请求计为 1 次调用，无论请求成功或失败。批量请求按实际请求数计算。
Q: 查询次数什么时候刷新？A: 每日 00:00 (UTC+8) 刷新当日查询次数，未使用的次数不累积。
Q: 如何查看会员使用情况？A: 在"会员中心"可查看各项权益的使用情况和剩余次数。
