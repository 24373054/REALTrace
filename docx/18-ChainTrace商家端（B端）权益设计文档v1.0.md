1. 企业会员体系概述
1.1 设计理念
ChainTrace 企业会员体系面向 B 端客户 (加密货币交易所、区块链项目方、金融机构、安全公司等)，提供专业化的链上风控、合规审查和深度分析服务。通过分层权益设计，满足不同规模企业的需求。
1.2 设计原则
- 企业导向: 权益设计围绕企业核心需求
- 按需付费: 根据使用量和企业规模定价
- 灵活配置: 支持定制化配置和扩展
- 服务保障: 提供 SLA 保障和专属服务
- 持续优化: 根据反馈持续优化权益

2. 试用版会员 (Trial)
2.1 基本信息
- 价格: ¥0 (14 天免费试用)
- 试用期限: 14 天 (不可延长)
- 转正方式: 试用结束后需购买正式会员
- 适用场景: POC 测试、产品评估
2.2 核心权益
API 调用权益
- API 调用次数: 1000 次/14 天
- API 速率限制: 10 次/分钟
- 可用接口: 核心接口 (地址查询、交易查询、风险评分)
- 数据深度: 标准深度
风控服务权益
- 风控策略: 基础策略 (3 个预设策略)
- 实时监控: ❌ 不可用
- 风险拦截: ❌ 不可用
- 黑名单管理: ✅ 可用 (最多 100 个地址)
合规服务权益
- KYC 审查: ✅ 可用 (最多 10 个/天)
- AML 审查: ✅ 可用 (最多 10 个/天)
- 合规报告: ❌ 不可用
- 监管对接: ❌ 不可用
分析服务权益
- 链上分析: ✅ 可用 (最多 5 次/天)
- 行为分析: ❌ 不可用
- 聚类分析: ❌ 不可用
- 模式识别: ❌ 不可用
报告服务权益
- 报告生成: 5 次/14 天
- 报告模板: 基础模板 (3 个)
- 报告格式: PDF
- 定时报告: ❌ 不可用
支持服务权益
- 技术支持: 社区支持
- 文档访问: ✅ 完整文档
- SDK 下载: ✅ 基础 SDK
- 培训服务: ❌ 不可用
2.3 使用限制
- 试用期限 14 天，到期后自动失效
- 数据不保留，试用结束后清空
- 不可用于生产环境
- 无 SLA 保障
2.4 转正优惠
- 试用期间购买享 9 折
- 试用数据可迁移到正式环境
- 专属销售顾问对接

9. 续费管理
9.1 自动续费
- 开启方式: 企业控制台 → 账户设置 → 自动续费
- 扣费时间: 到期前 30 天发送续费提醒，到期前 7 天自动扣费
- 扣费失败: 连续 3 次扣费失败后暂停服务
- 关闭方式: 随时可关闭，当前周期结束后生效
9.2 手动续费
- 续费入口: 企业控制台 → 账户管理 → 续费
- 续费优惠: 提前 30 天续费享 95 折，提前 60 天享 9 折
- 续费保期: 续费后有效期顺延
9.3 合同管理
- 合同期限: 通常 1 年起签
- 合同续签: 到期前 90 天启动续签流程
- 合同变更: 支持中途升级/降级

10. 退款政策
10.1 退款条件
- 7 天无理由: 签约 7 天内可申请退款 (未使用服务)
- 服务不达标: SLA 未达标可申请部分退款
- 合同解除: 双方协商一致解除合同
- 企业破产: 提供破产证明可申请退款
10.2 退款流程
```Plain Text
1. 提交退款申请 (说明退款原因)
2. 客服审核 (3-5 个工作日)
3. 技术评估 (如需要，5-10 个工作日)
4. 财务审核 (3-5 个工作日)
5. 审批通过 (对公退款，5-10 个工作日)
6. 退款完成
```
10.3 退款说明
- 已使用的服务按比例扣除
- 定制开发费用不退
- 私有部署费用不退
- 退款原路返回 (对公账户)

11. 常见问题
11.1 购买相关问题
Q: 如何选择合适的会员等级？A: 建议先申请 14 天试用，根据实际使用量选择。也可联系销售顾问进行需求评估。
Q: 可以中途升级/降级吗？A: 支持。升级立即生效，降级当前周期结束后生效。
Q: 支持分期付款吗？A: 支持。年付可分 2-4 期支付，需签订合同约定。
11.2 使用相关问题
Q: API 调用次数怎么计算？A: 每次 API 请求计为 1 次，无论成功或失败。批量请求按实际请求数计算。
Q: 超出调用次数怎么办？A: 超出后 API 返回 429 错误。可购买额外配额包或升级会员。
Q: 可以多人使用吗？A: 可以。企业版支持多个子账号，每个子账号有独立权限。
11.3 技术相关问题
Q: 支持私有化部署吗？A: 企业版和旗舰版支持。需要额外评估部署环境和费用。
Q: 数据安全性如何保障？A: 企业数据加密存储，支持私有部署，签订数据保密协议。
Q: 如何对接现有系统？A: 提供完整 API 文档和 SDK，专属技术团队协助对接。
11.4 服务相关问题
Q: 技术支持响应时间多久？A: 标准版 24 小时，专业版 4 小时，企业版 15 分钟，旗舰版 5 分钟。
Q: 提供培训服务吗？A: 专业版提供线上直播培训，企业版和旗舰版提供专属培训。
Q: 有成功案例可以参考吗？A: 有。联系销售可获取脱敏后的案例介绍。
